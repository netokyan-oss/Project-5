# Programming Project 5 – Tab Completion

## Overview
This project uses a Trie data structure to construct a tab completion software. It searches for words that match a specified prefix and keeps dictionary words.

## Characteristics
Include words in a trie. Verify the existence of a term.
Locate every word that has a prefix.
Show the top K word completions.
Completions are sorted by rank.
Determine the Trie's height and node count.

## Key Subjects
The Trie and word completion techniques are implemented in `Trie.java`.
Each node in the Trie is represented by the file `TrieNode.java`.The linked list and truncate methods are implemented in `LinkedList.java`.
The binary search tree and sort function are implemented in `BinarySearchTree.java`.
- `TabComplete.java`: Launches the application.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `TabComplete.java`.
3. Run the program.
4. Enter a dictionary file when prompted.
5. Enter a prefix to receive word suggestions.
